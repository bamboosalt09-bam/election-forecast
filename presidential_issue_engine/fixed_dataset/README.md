# Fixed Dataset

This directory contains reference CSVs used by the active presidential
issue-vote engine.

Most files are stable model inputs, including standardized presidential results,
bloc history, issue keywords, issue importance, region sensitivity, campaign
terms, economic/housing context, and event/configuration tables.

Use the engine commands from `presidential_issue_engine/README.md` to reproduce
current metrics. Do not edit these files as ad hoc labels for a target election.
