# 국회 발언 문맥 분류 실험 결론: 태도보다 의제 현저성

## 후속 결정: 제한형 설명 레이어 재활성화

초기 결론에서 문장별 stance를 전부 비활성으로 두었으나, 분류 개선 자체가 이슈의
성격을 설명하는 데 기여한다는 점을 다시 반영했다. v14 ambiguity gate 결과를 후보
득표에 직접 더하거나 빼지 않고, 이슈별 성격과 후보 연결 신뢰도를 보강하는 제한형
overlay로 재활성화한다.

- 입력 문장: 5,000개
- ambiguity gate 이후 방향 문장: 54개
- 부호 없는 정보로 유지되는 중립 문장: 4,946개
- character gain: `0.04`
- candidate-link gain: `0.01`
- 직접 후보 득표 조정: 없음
- 이슈 salience 배율 범위: 약 `0.9991~1.0010`
- 후보 link 배율 범위: 약 `0.9977~1.0023`

변경 전 원본 CSV와 전체 경로를 비교하면 rolling 행 MAE는
`3.70907176 → 3.70929828%p`, 득표수 가중 rolling MAE는
`3.71838195 → 3.71850749%p`, LOEO는 `4.98025592 → 4.98053617%p`였다.
차이는 사실상 0이지만 개선은 아니므로, 이를 예측 성능 향상 증거로 보고하지 않는다.
재활성화의 목적은 설명 가능한 이슈 성격 변수를 보존하는 것이며 배율은 예측을 크게
움직이지 않도록 제한한다.

재현 파일은 다음과 같다.

- `outputs/assembly_stance/stance_nli_ambiguity_v14/explanatory_overlay/application_state.json`
- `outputs/assembly_stance/stance_nli_ambiguity_v14/explanatory_overlay/forecast_validation.json`
- `scripts/build_stance_explanatory_overlay.py`
- `scripts/evaluate_stance_explanatory_overlay.py`

## 기록 목적

이 문서는 2026-07-17까지 수행한 국회 발언 문장 분류 실험의 결과와 모델 설계
결정을 보존한다. 핵심 결론은 다음과 같다.

> 국회 발언록은 후보·정당에 대한 여론의 긍정·부정을 직접 추정하는 자료보다,
> 정치권에서 어떤 이슈가 얼마나 크게 다뤄지는지를 측정하는 자료로 사용하는 편이
> 더 안정적이다.

이 결론은 회의록 원문이나 5.8GB 규모의 추출 자료가 불필요하다는 뜻이 아니다.
원문은 이슈 발생, 발언량, 확산, 가속, 지속, 대상 연결을 측정하기 위한 핵심 자료로
계속 보존한다. 문장별 태도 분류 결과만 활성 득표율 산식에서 제외한다.

## 평가 경계

- rolling warmup: 1997 대선
- scored elections: 2002, 2007, 2012, 2017, 2022 대선
- 2025 대선 결과: 학습, 선택, 비교에 사용하지 않음
- 분류기 자체의 상태: shadow
- 집계된 제한형 이슈 설명 overlay: 활성
- 활성 forecast의 `overlay_gain`: `0.04`
- 수동 이슈 seed: 비활성
- 국회 발언 기반 자동 이슈 seed와 중립 이슈 문맥: 유지

## 실험 질문

1. 국회 발언 문장을 긍정·중립·부정으로 충분히 정밀하게 분류할 수 있는가?
2. 질문, 인용, 반론, 제3자 평가와 실제 발언자 태도를 분리할 수 있는가?
3. 고신뢰 방향성 신호가 득표율 rolling 또는 nested 성능을 안정적으로 개선하는가?
4. 방향을 버리고 중립 정보와 이슈 현저성만 사용하는 편이 더 견고한가?

## 분류기 감사 결과

### 정밀도 우선 선택적 분류

| 모델 | 개발 OOF 방향 커버리지 | 기존 engineering holdout 커버리지 | 관찰된 유해 오류 |
|---|---:|---:|---:|
| TF-IDF precision v1 | 16.22% | 11.76% | 0 |
| hard-risk ensemble v2 | 19.82% | 14.71% | 0 |
| augmented TF-IDF v3 | 19.82% | 17.65% | 0 |
| augmented ensemble v4 | 23.42% | 20.59% | 0 |

오류를 억제하면 대부분의 방향 문장이 중립으로 내려갔다. v4에서도 유해 오류율의
단측 95% 상한은 개발 OOF `10.88%`, 기존 holdout `34.82%`였다. 관찰 오류가 0이라는
사실만으로 실제 오류율이 충분히 낮다고 결론 내릴 수 없었다. 이 holdout은 개발 과정에서
반복 사용되었으므로 독립적인 최종 검증 표본도 아니다.

### 문맥 인코더와 NLI

- NLI 신규 locked audit: 방향 출력 40건 중 27건만 올바름
- 중립 문장을 방향 문장으로 잘못 출력: 13건
- 방향 정밀도: `67.5%`
- 유해 오류율: `32.5%`
- 유해 오류율 단측 95% 상한: `46.63%`

후속 ambiguity gate v13 locked audit에서도 34건을 모두 방향으로 출력했고, 중립 6건을
전부 방향으로 오판했다. 방향 반전은 없었지만 방향 정밀도는 `82.35%`, 출력 중 유해
오류율은 `17.65%`, 단측 95% 상한은 `31.89%`였다.

주요 오류 원인은 다음과 같았다.

- 인용된 타인의 발언을 현재 발언자의 태도로 귀속
- 질문과 확인 요구를 확정적 비판으로 해석
- 정부가 정책을 설명한다는 사실을 정책 지지로 해석
- 한 문장에 등장한 다른 후보·정당을 잘못된 대상으로 선택
- 앞뒤 문맥에서 반박되는 주장을 현재 문장만 보고 채택
- 정치적 공방의 강도를 유권자 지지 방향으로 잘못 변환

## Forecast 연결 결과

엄격한 through-2022 성능 선택 과정에서 문장별 이슈 성격 overlay는 채택되지 않았다.
각 nested 선택 단계의 `overlay_gain`은 `0.0`으로 남았다. 후보 직접 태도 신호는
대상·정당 coverage gate를 통과하지 못했고, 강제로 이슈 방향 신호를 확대하는 실험도
nested 개선을 재현하지 못했다. 이후 설명력 보존을 목적으로 `0.04` 제한형 overlay를
별도 정책으로 재활성화했으며, 이는 nested 성능 선택 결과로 해석하지 않는다.

현재 활성 모델의 재현 기준 성능은 다음과 같다. 아래 수치는 문장별 stance 분류를
활성 입력으로 사용하지 않는다.

| 지표 | 현재 값 |
|---|---:|
| capped strict nested, 득표수 가중 지역 macro MAE | 4.613552%p |
| active rolling, 지역×후보 행 MAE | 3.709298%p |
| active rolling, 득표수 가중 지역 macro MAE | 3.718507%p |
| LOEO, 지역×후보 행 MAE | 4.98%p |
| rolling 전국 점 MAE, 선거 동일가중 사후 진단 | 2.473813%p |

따라서 문맥 분류 결과를 후보 득표 방향으로 직접 연결할 통계적 근거는 현재도 없다.
활성 연결은 이슈 성격과 link 신뢰도에 한정하며 영향 범위를 매우 작게 제한한다.

## 해석

국회 발언의 방향은 유권자 태도와 동일하지 않다. 야당의 공격, 여당의 방어, 의사진행상
질문과 답변은 정치권의 관심과 갈등 강도를 보여주지만, 어느 후보가 실제 득표 이익을
얻는지는 지역구도, 정당 prior, 후보 경쟁력, 정부 책임, 경제 환경과 결합해야 결정된다.

반면 이슈의 등장과 확산은 비교적 안정적으로 관측할 수 있다. 긍정과 부정을 정확히
구분하지 못하더라도 여러 정당과 위원회가 같은 이슈를 반복적으로 다룬다는 사실은 그
이슈의 정치적 중요도가 커졌다는 증거가 된다.

## 채택한 활용 원칙

국회 발언록에서는 다음과 같은 **부호 없는(unsigned) 정보**를 우선 산출한다.

1. 이슈별 발언량과 과거 기준 대비 이상 증가량
2. 주·월 단위 증가 속도와 가속도
3. 정당, 위원회, 발언자 사이의 확산 범위
4. 선수와 실제 직위에 따른 발언 중요도
5. 선거일까지의 시간감쇠와 장기 잔류 효과
6. 탄핵·계엄·부패 등 사건 유형별 기본 충격 강도
7. 후보·정당 직접 언급량과 대상 연결 신뢰도
8. 동일 이슈를 자당과 타당이 동시에 다루는 교차 진영 확산도

개념적으로 사용할 기본 구조는 다음과 같다.

```text
issue_salience
  = abnormal_volume
  * acceleration
  * cross_party_breadth
  * speaker_importance
  * time_decay_and_persistence
  * shock_class_weight
  * source_confidence
```

후보별 득표 방향은 이 값에서 직접 만들지 않는다. 정부·여당 책임, 후보 이슈 소유권,
정당 및 지역 prior, 후보 경쟁력, 당시 경제·주택 환경을 사용하는 별도 구조에서 결정한다.

## 사용하지 않을 신호

- 일반 문장의 긍정·부정을 후보 득표 증감으로 직접 변환
- 자당의 옹호 발언량을 후보 지지율로 직접 가산
- 타당의 공격 발언량을 후보 득표율에서 직접 차감
- 분류 확률이나 argmax를 근거로 후보별 연속 가중치 생성
- 중립 문장에 임의의 긍정·부정 부호 부여

중립 문장은 버리지 않는다. 방향은 0으로 유지하되 이슈 현저성, 확산, 정보량 계산에는
포함한다.

## 향후 재검토 조건

문장별 stance를 다시 활성 후보로 검토하려면 최소한 다음 조건이 필요하다.

- 개발에 사용하지 않은 신규 locked audit
- 중립→방향 및 방향 반전 오류에 대한 충분히 낮은 신뢰구간 상한
- 발언 주체, 인용 주체, 평가 대상을 분리한 target-attribution 통과
- strict nested rolling에서 일관된 개선
- 특정 한 선거의 개선에 의존하지 않는 선거별 비열화 검사
- 현재 salience-only 구조보다 복잡도 대비 명확한 추가 설명력

그 전까지 stance 분류기 자체는 shadow로 보존하고, 활성 모델에는 제한형 집계 overlay만
사용한다.
