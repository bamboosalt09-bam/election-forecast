# The 2025 forecast path was unrunnable, and the published forecast was stale

## Status

- Date: 2026-08-23
- Status: **diagnosed and repaired**; the 2025 artifact is regenerated as V29
- Found while promoting V29; the fault itself predates V29

## Symptom

Every run of the 2025 demonstration was rejected by the prospective harness's
own guard:

```
prospective harness does not reproduce frozen V25 history:
maximum absolute difference=0.003619628460480362
```

`scripts/run_prospective_forecast_v28.py` failed with a bit-identical
difference, so this was not introduced by V29.

## Cause

`8d7851b "Enforce the external-model-free V28 boundary"` made
`external_model_free_runtime()` set `POLL_PROJECT_BLOCK_EXTERNAL_MODEL_SEEDS=1`
and `POLL_PROJECT_ENHANCED_ISSUES=0` process-wide, so the engine stopped reading
`mega_issue_axis.csv` and `mega_issue_attribution.csv`.

The harness builds the 2025 target on `base.run("v25")`, and that call asserts
byte-identical reproduction of the **frozen V25** history. V25 was frozen *with*
those seed inputs. Under the enforced boundary the assertion cannot hold, and it
should not: the harness was being asked to match a baseline built under a
different runtime.

Confirmed by elimination:

| test | result |
| --- | --- |
| V28 prospective runner | fails, 0.003619628460480362 |
| V29 prospective runner | fails, same value |
| KOSPI fixed-dataset path replaced with the pre-`15f29f9` computation | fails, same value |
| **V27 prospective runner (no boundary guard)** | **runs** |

The KOSPI fixed dataset was the first hypothesis and was wrong; it is recorded
here so it is not re-investigated.

## The part that was not just reproducibility

`outputs/prospective_pres_2025_v28/` was committed at `f925637`, before
`8d7851b`. It was therefore produced **with** the external-model-derived seed
inputs that V28 documents as removed. The published 2025 forecast did not
satisfy the boundary it was published under.

## The repair

The guard's premise — the harness must not alter history — is right; its
baseline was wrong once the runtime changed. Three changes:

1. `base.run` takes a `canonical_dir`, so a caller that enters the boundary
   declares which frozen history applies instead of weakening the check.
2. `scripts/build_external_model_free_v25_baseline.py` freezes that history by
   running the **V25 model runner** inside the boundary. Running the *model*
   rather than the harness is the point: the guard still checks the harness
   against the model, with only the runtime aligned. A baseline generated by
   the harness would reduce the check to the harness reproducing itself.
3. `scripts/run_prospective_forecast_v28.py`, which is where the boundary is
   entered, points the guard at that baseline.

The 2025 artifact is then regenerated as `outputs/prospective_pres_2025_v29/`.

## What regenerating changed

Against the published V28 artifact, decomposed:

| source | regional max | regional mean | national max |
| --- | ---: | ---: | ---: |
| honouring the boundary | 0.0359 %p | 0.0103 %p | 0.006484 %p |
| V29 dispersion expansion | 2.6703 %p | 0.6970 %p | **0** |

The winner and the candidate ordering are unchanged. Every national movement
comes from finally honouring the boundary, and it is small — 0.0065 %p — which
is itself the evidence that the V28 removal claim was substantively true even
while the artifact contradicted it. The regional movement is the V29 transform,
which conserves the national levels by construction (measured shift `5.6e-15`).

2025's expansion is feasibility-capped: the nominal factor `1.086615` becomes
`1.081279`, because the full expansion would drive a regional share below zero.

## Why nothing caught it

No CI job ran the 2025 path. `clean-reproduction` rebuilds the *historical*
model only. Eight jobs stayed green across the entire window in which the
published forecast became unreproducible.

`scripts/verify_v29_prospective_reproduction.py` is now a CI job
(`prospective-reproduction`). It rebuilds the 2025 demonstration and compares it
with the frozen artifact, so this class of failure is visible from now on.
